## How to run (GymRats)

The Flutter app is in [`gymrats_app/`](gymrats_app). On the `feat/pose_setup` branch only the pose setup step exists, and it runs through a demo entry point:

```
cd gymrats_app
flutter pub get
flutter run -t lib/demo/pose_setup_demo.dart -d <device-id>
```

Plain `flutter run` shows only a "GymRats" placeholder. See [`gymrats_app/README.md`](gymrats_app/README.md) for prerequisites, what to check, debug logs, and running on an emulator.
