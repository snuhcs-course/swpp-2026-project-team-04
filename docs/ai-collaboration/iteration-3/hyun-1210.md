## c. What AI did well
- Replay infrastructure: every rule change was replayed over all recorded sets before it went in (12 labelled sets,
  94 labelled reps), e.g. the 3-frame top fold the user proposed was dropped because the replay showed it lost two knee
  reps (`docs/iteration-3/pushup-error-cases.md`, "After the judge fix").
- Setup diagnosis from recorded setup frames: 492 of 506 "Get into a push-up" frames failed only on the torso drop,
  which matched the user's report that kneeling passed setup (`setup_checker.dart`, `maxPushUpTorsoDrop`).
- Found a recording artifact before it became a rule bug: the shin rule rejected normal rep 7 of
  `20261027-142341_normal` because the user walked back from the phone between reps; limiting the rule to the last 10
  top frames fixed it.

## d. Hallucinations / errors
- Claimed the shoulder drop overlaps between head nods and valid reps; that was the raw measure, the judge's smoothed
  measure separates them (0.57–0.90 vs 0.75–0.98). Caught by re-measuring; corrected to the user.
- Proposed widening the knee–hand line to −0.35 as the next check; the replay showed it rejects 31 normal reps and
  catches 3 of the 4 counted knee reps, so it was dropped.
- Proposed setup line 1.2, then measured plank tops at 1.05–1.22 and revised to 1.5 before any code change.
- Checking the bow before `armsStraight` turned four straight-arm knee reps into `kneesDown`; caught by the replay
  test, reverted.
- The shoulder gate failed 51 synthetic tests because `pushUpFrame` kept the shoulders fixed; fixed in the shared
  test support with a user-approved exception. Reviewer round 1 on H2 returned CHANGES_REQUESTED (5 Major), all fixed.

- Proposed loosening the shoulder line to 0.66/0.67 for two shallow reps; the user questioned the risk, the replay
  showed ten rejected reps would then rely on other checks, and the code kept 0.70 (8d3431c).

- Said a straight-arm head dip on the toes closes as `armsStraight`, and wrote it into set 8 of the recording standard.
  `_armsNeverBent` needs `_kneesDown()`, so on the toes the judge shows "Go lower" or nothing. Caught when reading the
  code to answer the PM's question on set 8; the set became a straight-arm kneeling bow (PDF rebuilt 2026-10-30).

- Wrote set 4 of the recording standard as coming up to "about 140°" and told the PM it would give
  `incompleteExtension`. Replay of a recorded set: at that height the head is only about 0.13 shoulder widths below the
  top and the front-view elbow reads 166-179°, so the judge treats it as the top. Caught when the user said reps were
  counted with bent arms; raised with the PM in the PR notes (2026-10-31).
