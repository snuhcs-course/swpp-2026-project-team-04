- **Trial merges before merging:** the trial merge of #72 then #73 showed that they conflict only in
  `test/screens/online_preparation_test.dart` (5 hunks; keep both sides), so #73's owner merged main before his PR
  went in; #73 merged at `c5f356e` with its CI green.

  recorded exception. The agent flagged it, the PM merged on his own call, and the owners' consents were collected
  later the same day.

  rep of JP's set 1 normal recording rejected as `kneesDown`, and no extra knee cheat caught. With the frame check
  (28–30% vs 41% "touching"), this backed the decision to keep the rule off by default when #75 merged.

  read `app.dill`); the agent built from an ASCII-path worktree instead, which made the UAT APK. TODO(hyun-1210):
  rough time saved per case.

## d. Hallucinations / errors
- **Sheet write overwrote the team's edits** (11-11 23:59): the agent wrote the User Story cells C6:C11 of the UAT
  sheet over edits the team had made in its meeting a few minutes earlier. Restored on 11-12 from the 23:55 version,
  which the PM pasted in.
- **Writes into shifted rows** (11-18): a teammate inserted a row (A12) while the agent filled the PM rows, so its
  writes for P22 and P26–P28 landed one row off. Caught by re-reading the range; corrected and re-read. Lesson kept:
  re-read the row positions right before each write when others edit the sheet.
- **Wrong commit hash in a merge call** (#75, 11-18): the first merge attempt passed a wrong full SHA to
  `--match-head-commit`, and GitHub refused it. The guard worked as intended; the merge went through with the right
  head `076c438`.
- **Wrong notes on the merge-order page** (11-15): the page said W6 could start with J4 and kept old J5 mockup text;
  corrected in the next version.
